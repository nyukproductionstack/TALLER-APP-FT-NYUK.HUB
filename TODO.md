# TallerApp — entregables

## Panel de inicio y navegación
- [x] La app muestra un panel de inicio con métricas de citas, ingresos, citas de hoy y próxima cita.
- [x] La navegación permite cambiar entre Inicio, Citas, Nueva cita y Reportes.
- [x] La interfaz conserva el estilo oscuro automotriz con acentos naranja y funciona en celular y computadora.

## Gestión de citas
- [x] Se cargan como contenido inicial los 20 registros entregados en `App.js`.
- [x] El listado muestra cliente, vehículo, placa, servicio, mecánico, fecha, hora, observaciones y costo.
- [x] La búsqueda permite localizar por cliente, placa, vehículo, servicio o mecánico.
- [x] Se puede filtrar por servicio, mecánico y fecha.
- [x] Se puede crear una cita con cliente, placa, marca, modelo, año, fecha, hora, servicio, mecánico, costo y observaciones.
- [x] Se puede editar una cita existente con el formulario precargado.
- [x] Se puede eliminar una cita después de una confirmación previa.
- [x] Los cambios CRUD se conservan en el navegador para reabrir la app sin perder la información de prueba.

## Reportes
- [x] La vista de reportes resume ingresos totales, promedio por cita y cantidad de citas.
- [x] Los reportes agrupan resultados por servicio y por mecánico con barras comparativas.
- [x] Se puede exportar el listado visible a CSV.
